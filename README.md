# 🚀 FlowSight

### 🗺️ Google Maps for Code

> **Understand your codebase. Visualize the flow. Trace the data.**

FlowSight turns JavaScript codebases into interactive visual graphs, helping developers understand how different parts of an application connect and how data moves through the system.

---

## ✨ Features

🗺️ **Application Flow**  
Visualize how your application works from a high-level view.

🔍 **Code Exploration**  
Explore modules, files, functions, and implementation details.

📦 **Data Flow**  
Trace data such as `email`, `password`, `user`, and `token`.

🔗 **Cross-File Analysis**  
Understand connections between routes, controllers, services, and databases.

💻 **Source Inspector**  
Jump from graph nodes directly to the related source code.

🌿 **Branch-Aware Flow**  
Understand different `YES / NO` execution paths.

⚡ Getting Started
1. Clone
git clone https://github.com/YOUR_USERNAME/FlowSight.git
cd FlowSight

2. Start Backend
cd backend
npm install
npm run dev

3. Start Frontend
cd frontend
npm install
npm run dev

Open:
http://localhost:5173
